# Tableau Dashboard Guide
Connect to `orders.csv`, `order_stops.csv`, `monthly_kpis.csv`, and `zone_kpis.csv`.

1. **Pilot Operations:** total orders, completion rate, average elapsed minutes, orders by zone, elapsed time by speed.
2. **Retailer Fulfillment:** stops and exception counts by retailer; preparation and waiting time.
3. **Unit Economics:** import `data/unit_economics_scenarios.csv`; compare commission, delivery revenue, partner payout, payment cost, and refund exposure.
4. **Customer & Membership:** membership order mix, delivery speed mix, fees and surcharges.

Every dashboard must display: “Synthetic illustrative data; not actual company transactions.” No native Tableau workbook (.twb/.twbx) is included.
