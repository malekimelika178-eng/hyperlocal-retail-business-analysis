# Data Dictionary

All order-level records are synthetic and illustrative.

- **order_id** — Order id.
- **order_datetime** — Order datetime.
- **zone** — Zone.
- **delivery_speed** — Delivery speed.
- **order_status** — Order status.
- **retailer_count** — Retailer count.
- **merchandise_value_usd** — Merchandise value usd.
- **customer_delivery_fee_usd** — Customer delivery fee usd.
- **distance_surcharge_usd** — Distance surcharge usd.
- **commission_rate_assumption** — Commission rate assumption.
- **retailer_commission_usd** — Retailer commission usd.
- **retailer_transaction_fee_usd** — Retailer transaction fee usd.
- **partner_payout_usd** — Partner payout usd.
- **payment_processing_cost_usd** — Payment processing cost usd.
- **refund_amount_usd** — Refund amount usd.
- **prep_time_min** — Prep time min.
- **drive_time_min** — Drive time min.
- **retailer_wait_time_min** — Retailer wait time min.
- **total_elapsed_min** — Total elapsed min.
- **membership_order** — Membership order.
- **contribution_before_fixed_costs_usd** — Contribution before fixed costs usd.
- **month** — Month.

**Limitations:** Contribution before fixed costs is a simplified proxy, not profit. Dataset excludes tax, fixed overhead, support labor, insurance, chargebacks, marketing and provider settlement fees. Retailer prospects are unverified examples.
